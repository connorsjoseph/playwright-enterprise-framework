# Playwright Enterprise Framework

A robust end-to-end testing framework built with [Playwright](https://playwright.dev/) for enterprise-grade web applications. Includes Allure reporting, environment variable support, and utilities for working with CSV and Excel files.

## Features

- Automated browser testing with Playwright
- Allure reporting integration
- Support for environment variables via `.env`
- Utilities for CSV and Excel data handling
- TypeScript support

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository:
   ```
   git clone https://github.com/<your-username>/<repo-name>.git
   cd playwright-enterprise-framework
   ```

2. Install dependencies:
   ```
   npm install
   ```

### Running Tests

To run all Playwright tests:
```
npm test
```

### Allure Reporting

1. **Generate Allure report:**
   ```
   npm run allure:generate
   ```

2. **Open Allure report in your browser:**
   ```
   npm run allure:open
   ```

### Project Structure

```
playwright-enterprise-framework/
├── tests/                # Test files
├── src/                  # Source code and helpers
├── .env                  # Environment variables (optional)
├── package.json
└── README.md
```

### Scripts

- `npm test` - Run Playwright tests
- `npm run allure:generate` - Generate Allure report
- `npm run allure:open` - Open Allure report in browser
